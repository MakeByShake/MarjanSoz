# app/api — будущие серверные роуты для ИИ

Сейчас папка пустая. Сюда добавятся Route Handlers (серверный код Next.js, ключ API в браузер не попадает):

| Роут | Файл | Что делает |
| --- | --- | --- |
| `POST /api/explain` | `app/api/explain/route.ts` | Объясняет смысл мақала простыми словами, с примером из жизни |
| `POST /api/search` | `app/api/search/route.ts` | Умный поиск: «мақал про трудолюбие» → подходящие мақалы из `data/proverbs.json` |
| `POST /api/teacher` | `app/api/teacher/route.ts` | ИИ-учитель: диалог, проверка ответов, подсказки |

Ключ берётся из переменной окружения `ANTHROPIC_API_KEY` (см. `.env.example`).
Данные о мақалах для роутов читаются через функции из `lib/`.
